# Homework 2

## Run `Homework2.py`

Open a terminal in this folder and run:

```powershell
python Homework2.py
```

This runs one default falling-beam example and one simply-supported-beam example.

## Run the checks

```powershell
python Homework2.py --test
```

## Compute the Gradescope quantities

```powershell
python Homework2.py --answers
```

The `--answers` command runs the Part 1 and Part 2 simulations from the homework handout and prints the values needed for the multiple-choice questions.
