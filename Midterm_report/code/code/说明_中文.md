# 项目代码说明（中文，给自己看）

这份说明帮你快速看懂代码，方便老师当面问到时能解释。正式的英文说明在 `README.md`。

## 1. 这个项目在算什么

一根两端固支的薄片，把两端压近一点（预压量 `eps`），它会屈曲成拱形。拱朝上叫 open，
朝下叫 closed，两个都是稳定状态。在薄片上贴一小段驱动片（位置 `s_a`，长度 `l_a`），
驱动片的作用是改变这一段的**自然曲率**。自然曲率加到一定程度，open 状态失稳，
薄片“啪”地跳到 closed，这就是 snap-through。撤掉驱动后它保持在 closed。

设计问题：在保持力够大、应变不超限、闭合够快的前提下，选 `eps, s_a, l_a` 使驱动做功最小。

## 2. 文件和运行顺序

在 `code` 文件夹里依次运行：

```
python beam.py            # 1 秒，检查向量化的梯度/Hessian 和课程函数一致
python validate.py        # 约 3 分钟，五项验证
python design.py grid     # 约 12 分钟，357 个设计的扫描
python design.py search   # 约 6 分钟，Nelder-Mead 搜索最优设计
python make_figures.py    # 约 1 分钟，设计部分的图
python convergence.py     # 约 1 分钟，最优设计的时间步和网格收敛
```

- `beam.py`：梁的定义、能量、梯度、Hessian、静力 Newton、隐式欧拉时间步。
- `snap.py`：屈曲、点力加载、驱动片触发、snap 动力学。
- `theory.py`：用来对照的理论公式。
- `validate.py`：验证。`design.py`：设计评估和搜索。`make_figures.py`：画图。`convergence.py`：最优设计的时间步、网格收敛检查。
- `course/`：课程原始函数，只用来核对 `beam.py`。

## 3. 需要能讲清楚的几个点

**自由度。** 自由跨度分成 N 段，两端各多一段夹在夹具里，共 N+3 个节点。
每端夹住两个节点（位置和斜率都固定），所以固定 8 个自由度，自由的有 2(N-1) 个。

**能量。** 和课上一样：拉伸能 + 弯曲能。离散曲率 `kappa_k = 2 tan(phi_k/2)`，
`phi_k` 是节点处的转角。弯曲能是 `1/2 * EI/l_k * (kappa_k - kappa0_k)^2`，
`kappa0_k` 就是自然曲率，驱动片通过它起作用（课上 Module 17 的驱动方式）。

**为什么重写了梯度和 Hessian。** 课程函数一次只算一个节点，在 Python 循环里很慢。
`beam.py` 用 NumPy 数组一次算所有节点，公式完全相同，`python beam.py` 显示两者相差 1e-16。

**夹持节点的 Voronoi 长度取 dl/2。** 夹持节点的 Voronoi 单元有一半在夹具里，不能弯，
所以能弯的长度只有 dl/2。不这样做的话，屈曲载荷误差随网格只是一阶收敛（N=40 时差 5%）；
改了以后 N=40 只差 0.2%。这是 pilot 里发现的问题的修正。

**静力求解和稳定性。** `static_solve` 用 Newton 法解 `grad E = F`。解出来以后算自由
Hessian 的最小特征值 `lam_min`：大于 0 是稳定平衡，小于等于 0 是不稳定。
触发曲率 `kcrit` 就是一点点加大自然曲率，直到 `lam_min` 降到 0 的那个值（`snap.trigger`）。

**屈曲怎么算出来的。** 直梁压过欧拉载荷后仍然是平衡，但不稳定（`lam_min < 0`）。
这时沿不稳定特征向量推一下，再用强阻尼的隐式欧拉让它落到稳定的拱形（`snap.buckle`）。

**动力学。** `step_implicit` 就是课上的隐式欧拉 + Newton（proposal 的 Algorithm 1）。
Newton 不收敛时把时间步减半重算（`advance`）。隐式欧拉有数值耗散，所以另外写了梯形法
（`step_trapezoid`，没有数值耗散）做对照：两者算出的 snap 时间只差 0.5%。

**四个性能指标。**
- `kcrit`：open 状态失稳时的驱动曲率（乘以 L，无量纲）。
- `W_act`：驱动片到触发为止做的功。只统计驱动片向薄片输出能量的部分。
- `F_hold`：在 closed 状态的中点往回推，能顶住的最大力。只和 `eps` 有关。
- `t_snap`：阶跃指令（1.1 倍 `kcrit`）之后，中点第一次到达“指令保持时的稳定高度”的时间。

## 5. 设计结果（`results/grid.csv`、`results/search.json`）

要求：保持力 ≥ 0.5 N，闭合时间 ≤ 10 ms，弯曲应变 ≤ 1%。

| 设计 | eps | s_a | l_a | W_act | F_hold | 应变 | t_snap |
|---|---|---|---|---|---|---|---|
| 搜索得到的最优 | 1.53% | 0.269 | 0.136 | 0.197 mJ | 0.500 N | 1.00% | 4.7 ms |
| 网格里最好的点 | 2% | 0.275 | 0.2 | 0.487 mJ | 0.574 N | 0.82% | 5.2 ms |
| 驱动片居中（同 eps、l_a） | 1.53% | 0.5 | 0.136 | 3.30 mJ | 0.500 N | 0.75% | 3.6 ms |

结论：
1. 1/4 处是拱的拐点。驱动片在那里能让 open 状态失稳，但预压 ≤ 1.5% 时撤掉驱动后薄片又弹回 open；预压更大时能切换，但应变超过 1%。所以 1/4 点不是好位置。
2. 做功最小的位置在刚过 1/4 点的地方。最优设计比居中驱动省功约 17 倍。
3. 保持力只由 `eps` 决定，和理论公式吻合。最优解处保持力约束和应变约束同时起作用，时间约束不起作用。
4. `t_snap` 只是“第一次到达”的时间。阻尼比 0.02 时薄片会来回振荡超过 65 ms；
   阻尼比 0.10 时约 19 ms 后稳定在行程的 10% 以内。也就是说真正的闭合时间主要由阻尼决定。

## 6. 和 proposal 不一样的地方

1. 夹持节点 Voronoi 长度取 dl/2（见上）。
2. 触发曲率用静力延拓 + 稳定性判断来找，不再用缓慢的阻尼动力学加载。
3. `W_act` 只统计驱动片输出能量的部分。原公式在拐点附近会得到负功。
4. `t_snap` 的判据从 −0.9 w0 改成“指令保持时的稳定高度”（约 −0.6 w0），因为 −0.9 w0 不一定到得了。
5. 指令正负两个方向都试，取能切换且做功小的那个。实际上每个设计只有一个方向能触发：`s_a ≤ 0.25` 为负，以上为正。（最初按“驱动片在 open 状态的平均曲率反向”选方向，这个规则在 1/4 点平均曲率为零时会选错，已改掉。）
6. 增加了梯形法做对照。

这些改动在中期报告和 final report 里都要写明。

## 7. 老师可能问的问题

- **为什么用隐式方法？** 拉伸刚度 EA 比弯曲刚度大很多，显式方法的时间步会非常小。隐式方法稳定，但要解非线性方程，所以用 Newton。
- **隐式欧拉的数值耗散有多大？** snap 过程中时间步取 t*/4000 时，它耗掉了约 38% 的释放能量；但 snap 时间本身和无耗散的梯形法只差 0.5%。
- **居中驱动为什么费力？** 对称加载下，梁要先沿对称路径变形，直到分岔到非对称模态才翻过去；偏置驱动直接激发非对称模态。
- **F_hold 的理论公式哪来的？** 中点点力下，梁在轴力达到第二阶屈曲载荷（80.76 EI/L²）时转到非对称模态，此时的力就是峰值：Pandey 等论文的式 (3) 给出 `F L²/EI = 129.53·sqrt(eps − 80.76 S)`，`S = h²/(12L²)`，代码里直接用论文印出的常数。
- **为什么只用了 N=40？** 网格收敛表显示 N=40 和 N=160 的 `kcrit` 差 0.2%，`W_act` 差 0.2%。最优设计做了专门的收敛检查（`convergence.py`）：N=40 时各量与 N=160 相差 < 1%，驱动功差 2.5%。
- **为什么梯形法在 t*/250 失败？** 梯形法没有数值阻尼，代码里也没给它加步长减半，大步长下 snap 过程的 Newton 迭代不收敛。隐式欧拉有步长减半，所以不会失败，但有数值耗散。
